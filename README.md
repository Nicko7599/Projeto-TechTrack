# TechTrack — Controle de Ativos de TI

O **TechTrack** é um sistema desenvolvido para auxiliar empresas de pequeno, médio e grande porte a cadastrar, localizar e acompanhar equipamentos de informática (notebooks, desktops, etc.), garantindo maior rastreabilidade e histórico de movimentações.
